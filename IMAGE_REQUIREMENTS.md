# Loyalty Tour Image Requirements

## Image Specifications

**Aspect Ratio:** 4:3 (Width:Height)

**Recommended Dimensions:** 
- 800px × 600px (optimal)
- 1200px × 900px (high resolution)
- Minimum: 640px × 480px

## Image Locations

Place your images in the `/public` folder with the following names:

1. **tour-intro.jpg** - Introduction/Welcome page
   - Should convey excitement and welcome feeling
   - Suggestion: Happy customers, loyalty cards, or welcoming imagery

2. **tour-earn.jpg** - How to Earn Points page
   - Should show earning methods
   - Suggestion: Shopping bags, store front, online shopping imagery

3. **tour-gift.jpg** - Welcome Gift page (25 Free Points)
   - Should emphasize the gift/reward
   - Suggestion: Gift box, celebration, points/coins imagery with "25" prominent

## File Format

- **Format:** JPG, PNG, or WebP
- **Optimization:** Keep file size under 200KB for fast loading
- **Quality:** 80-85% JPEG quality is sufficient

## Notes

- Images will be displayed with rounded corners (16px border-radius)
- Background color fallback is provided if images fail to load
- Images are centered and will cover the container maintaining aspect ratio
- On mobile, images take full width with the same 4:3 aspect ratio
